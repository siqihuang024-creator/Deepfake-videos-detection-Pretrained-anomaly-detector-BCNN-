# 作业 313 后的低成本对照

目的：两套贝叶斯头在 100 真/100 假的同一 DFDC 开发集上 AUROC 仅为 46.81%/51.02%。先定位不训练网络的特征距离、确定性单类映射与贝叶斯版本之间的差别；不因此直接否定贝叶斯方法。

## 固定输入

复用 311 的两套特征缓存及 313 的确切单元、次序和角色：拟合 679 片段/352 来源，早停 169/88，校准 112/112，开发 200 视频/100 配对来源。程序读取原 `training_registration.json`、`training_units.csv`、模型锁、报告和参数，验证内容哈希、缓存指纹与重新核查的清单完全一致。参考贝叶斯算法文件必须保持原哈希。

先用保存的贝叶斯参数重放校准和开发分数，核对原 CSV 和混淆矩阵，不重新训练贝叶斯头。原分类概率也必须复现。不同运行时可能造成小浮点差别，分数比较容差 rtol=1e-5/atol=1e-7；超过容差直接失败，不静默混用结果。输出目录必须新建，313 原结果不覆盖。

## 三个对照

| 名称 | 操作 |
| --- | --- |
| `centroid_l2` | 只在拟合部分按来源均衡估计中心，计算原 1024 维特征到中心的平方欧氏距离。不训练投影网络，不使用早停或校准数据拟合中心。 |
| `deterministic_svdd` | 1024→512→128，无偏置、LeakyReLU，与原贝叶斯网络初始均值矩阵、输入中心化和初始 SVDD 中心一致。固定权重，不抽样，无 KL、无权重衰减。 |
| `deterministic_prior_matched_svdd` | 与上项相同，额外加入原高斯 KL 中依赖权重均值的惩罚：`KL_WEIGHT / 拟合来源数 × 1/2 × Σ(W² / prior_variance)`，各层 prior_variance=2/fan_in。它是点权重先验惩罚，不是完整贝叶斯 KL。 |

两种网络共用来源均衡数据权重、Adam lr=1e-3、batch128、seed42、最多100轮、patience12；早停只看原早停子集的加权距离。日志分别记录数据损失与正则项，参数均以无 pickle 的 NPZ 保存。判别分数仍为平方距离。初始化均值相同，但确定性网络的训练 RNG 不再被随机权重采样消耗，实际 minibatch 顺序与原贝叶斯版本不同。因此对照可以缩小问题范围，不能凭一次差异将原因唯一归为后验不确定性。

每种新方法各自在同一批 112 个真实校准单元上取 95%/99% 分位数阈值；不能按开发集标签调阈值。原贝叶斯/分类器保留原阈值。表格报告 AUROC、实际开发误报率/检出率，以及来源分组误报区间；名义5%校准目标不能写成开发集固定5%FPR。只有一个种子，无最终测试入口。既有 source-only 元数据不证明人物隔离。

结果包含：共同 `control_registration.json`、`training_units.csv`；每个编码器的 `control_heads.npz`、训练进度/历史、校准/开发分数、误报清单、报告和 `control_lock.json`；总表 `comparison.csv` 含两个编码器×五种评分方式×两个校准操作点，共20行；`completion.json` 标记整体完成。五种评分方式包括三个新对照及原贝叶斯/分类器参考。

若简单距离也差，说明该距离对本次跨来源任务无鉴别力，不能据此证明特征完全没有伪造信息（分类头已有可用信息）。若确定性版本明显优于贝叶斯版本，再检查随机权重、先验/KL强度及种子；若两类 SVDD 都差而分类器好，应优先检查单类映射目标是否保留伪造方向。所有判断均先限于这批开发数据，不立即扩大训练或打开最终测试。

## 已准备但不自动执行的较小 KL 权重对照

新增 `gad/bayesian_kl_ablation.py`、`scripts/run_segment_kl_ablation.py` 及 `slurm/segment_kl_ablation.sbatch`。保留原 `bayesian_svdd.py` 字节内容和 `KL_WEIGHT=1e-3`，不破坏作业 313 及现有对照的算法哈希锁。新实现沿用原初始化、输入中心、采样 RNG、来源权重和优化顺序；在同一 KL 系数下，通过单元测试确认参数、训练总损失和早停距离复现原实现。

正式后续只预设 `1e-4` 和 `1e-5` 两个系数，两个冻结编码器共四次小网络拟合；不重新提特征，不重训原 `1e-3` 基线。先检查三个确定性对照，再决定是否提交此入口。程序要求已有完成且锁定的对照结果，核对参考登记、完整单元、参数/报告哈希与对照总表；不会自行根据 AUROC 选择配置，也不会由现有对照任务自动启动。

每轮单独记录：训练总损失、来源加权距离项、原始 KL、按来源数归一化 KL、乘系数后的 KL、独立早停距离、最佳轮次和时间。其中四个训练损失量均由同批次、同一更新前状态计算，按批次样本数作整轮平均，可核对 `training_loss ≈ training_distance_loss + training_weighted_kl`。不能用早停距离代替训练距离项。

保存的最佳参数另报告实际 KL、加权 KL、两层权重均值绝对值/标准差及其比值中位数、原有坍缩诊断。新的每组阈值仍只用同一真实校准集的95%/99%分位数，所有指标只在原开发集检查。合并对照表包含原20行加新8行，共28行。改进仍属开发诊断，不能当作无偏最终测试证据。
