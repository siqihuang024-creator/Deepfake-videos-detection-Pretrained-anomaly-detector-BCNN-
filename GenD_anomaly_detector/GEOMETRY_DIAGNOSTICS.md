# 冻结特征的几何与来源诊断

承接 313、316、317 的开发实验。原官方特征中心距离 AUROC 82.85%，优于新投影头；当前任务检查协方差建模、单一分类方向的贡献和真实来源差异。旧实验文件、权重和哈希锁保留。NIW 暂缓。

## 本次固定的数据与工作范围

- 读取 311 的两套冻结编码器缓存，核对 313 的确切单元/次序/角色及 316 的锁定报告：拟合 679 片段/352 来源；早停169/88；真实校准112/112；DFDC开发200视频/100配对来源。
- 新统计模型只用 `gradient_fit` 拟合；早停数据只用于描述性分布报告，不用于选择收缩强度。Ledoit–Wolf 的收缩系数只从拟合来源估计，无新超参数网格。
- 原中心距离和分类概率必须复现316分数；原清单中不可评分及被排除来源的分母仍从参考登记保留。所有新阈值分别由同一112个真实校准单元的95%/99%分位数确定。
- 不解码图片、不重新提特征、不训练神经网络、不打开最终测试。方法设计已参考带标签开发集，不得将当前开发结果作为独立测试。
- 整个系统不是无伪造监督系统：冻结GenD曾接受真假监督，只有下游统计模型拟合与阈值校准只用真实视频。

## 三项问题

1. **协方差距离是否更好。** 先把每个拟合来源保留的1–2个片段向量取平均，再对352个来源均值调用 `LedoitWolf(store_precision=False)`。中心与来源均衡中心一致，协方差反映来源均值之间的变化，不单独估计来源内片段协方差，也不将679个片段当独立观察。评分用Cholesky求解的平方Mahalanobis距离，异常越大分数越高。
2. **单一分类方向有多大贡献。** 在CPU读取对应官方/微调模型，完整state哈希必须等于提特征时的记录。官方revision固定为缓存登记revision，分类器必须是1024→2、输入L2归一化的线性头。方向为 `normalize(w_fake - w_real)`，不从开发标签学习。
   原始特征均为每帧L2特征的均值，本身不再归一化。用只依赖该方向的Householder映射得到1023维正交补坐标，不重新归一化；统一变换拟合、早停、校准、开发数据，重新拟合中心/协方差和校准阈值。保存方向分量距离，核验 `原中心距离 = 方向分量平方距离 + 正交补中心距离`。线性logit均值与逐帧softmax概率均值不等价，不能把方向坐标叫作原分类概率。
3. **真实来源差异。** 输出各角色/来源真实视频的来源均值分数分位数，以及真实校准与DFDC真实视频之间的分数排序AUROC（不是深伪AUROC）。特征层另比较拟合A、校准A、DFDC真实样本的来源均值，报告均值向量距离和有偏RBF-MMD平方；核宽度仅由拟合A的来源间距离中位数确定。均为描述性诊断，无因果或显著性保证，MMD还受样本量不同影响。

最终表包含6种评分：原中心距离、原Mahalanobis、去分类方向后的中心距离/Mahalanobis、仅分类方向的平方中心距离、原分类头，共两编码器×六方法×两校准阈值=24行。

## 计算资源与输入

`slurm/geometry_diagnostics.sbatch` 申请4 CPU、16 GiB、`--time=0`，不申请GPU。读取缓存之外，只在CPU加载冻结模型来读取和验证分类器权重；不对图片做前向传播。官方权重和基础编码器必须已存在于远程HF缓存，脚本设定离线模式，缺失时应检查已有权重缓存，不自动下载其他revision。完整真实模型读取将在远程正式任务中验证；本地测试使用小型模拟模型验证state绑定和处理流程。

```bash
sbatch --time=0 GenD_anomaly_detector/slurm/geometry_diagnostics.sbatch \
  REFERENCE_313 CONTROLS_316 DATA_301 CACHE_311 SELECTION NEW_OUT
```

新建输出目录，不覆盖旧结果。输出包括共同 `geometry_registration.json`、`training_units.csv`、`classifier_directions.npz`，两个编码器各自的 `distance_heads.npz`、校准/开发/全单元分数、误报、来源摘要、MMD诊断和报告/锁；总表 `comparison.csv`、完成标记 `completion.json`。模型初始化细节另存 `*_model_load.log`。

AUROC区间按已知来源组bootstrap500次；不保证人物独立。真实开发误报另给Wilson区间，避免0误报产生退化的[0,0]区间；其二项假设仍未涵盖未知演员相关性。校准集上的操作点是拟合阈值后的经验量，不是独立误报保证。

分类方向去掉后若效果下降，只能说明分数依赖该方向，不能说明全部真假知识都在该方向；效果未下降也不能证明表征没有利用伪造监督。跨不同特征空间的中位数比例不能直接量化丢失了多少信息，应结合AUROC、配对评分和重新校准后的实际操作点。
